# 答题看电视

电视防沉迷：孩子答题赚观看时间，家长用手机管理。

目标设备：小米 S75 MiniLED（MiTV-MFTR0，Android 14，armeabi-v7a）。

本阶段只验证三件事：
1. 答对一题加 1 分钟（上限 60 分钟）
2. 余额在待机、重启、断电后不丢
3. 受管视频应用播放时才扣时，余额用完会暂停并打开答题页

## 构建

```bash
./gradlew assembleDebug
```

生成的安装包：`app/build/outputs/apk/debug/app-debug.apk`

## 题库

来源：「小学语数英题库收集」项目的输出，原样保存在 `bank/source/`（一至三年级上下册，共 6000 题）。

电视只能用遥控器选择，所以打包前用脚本把填空题全部转换成选择题：

```bash
python3 tools/build_bank.py
```

输出 `app/src/main/assets/bank.json`，转换报告在 `bank/build_report.txt`。题库更新后，重新运行脚本再打包即可。

家长页「教材进度」里可以设置册次、参与的学科，以及每个学科学到第几单元。出题时只从这个范围里抽题，各学科轮流出题，3 天内已奖励过的题排在最后。

## 家长手机 App（Android）

模块 `parent/`，安装包：`parent/build/outputs/apk/debug/parent-debug.apk`

```bash
./gradlew :parent:assembleDebug
```

功能：
- 自动在局域网里找到电视，输入电视上的 6 位配对码完成配对（可配对多台手机）
- 查看今日观看、答题、错题；手动增加或设定观看余额；家长模式直接解锁（不扣余额）
- 设置册次、学科、每个学科学到第几单元、参与出题的题型
- 拍照出题：拍课本或作业/试卷 → 发送前提示将发送的内容 → Claude 识别出题（存疑题标红、默认不勾选）→ 逐题核对修改 → 提交到电视
- 查看答题记录、错题、已导入题目（可删除）

拍照出题需要在 App 里填写 Claude API Key（只存在手机上）。模型 `claude-opus-5-5`，结构化 JSON 输出，开启服务端拒绝回退。

电视与手机之间的接口见 [docs/lan-api.md](docs/lan-api.md)。iOS 版待安装 Xcode 后按同一接口开发。

## 小米电视上的已知限制

- **不能常开调试浮层**：小米系统会强行停止带悬浮窗的应用（日志 `has system window, so kill it`），强行停止后无障碍权限也会被移除。浮层默认关闭，调试请用 `scripts/logs.sh`。
- **云视听极光屏蔽了无障碍**：收不到它的窗口事件，也读不到它的界面。前台应用改为从系统使用记录判断（需要"使用情况访问"权限，`grant.sh` 会授予）。
- **不要用 `am start -S` 或"强行停止"本应用**：同样会让无障碍权限被移除，需要重新运行 `scripts/grant.sh`。

## 安装到电视（需要家长确认后再执行）

| 脚本 | 作用 |
|---|---|
| `scripts/install.sh` | 打包、备份当前无障碍和通知设置到 `backups/`、安装、授权 |
| `scripts/grant.sh` | 只做授权：无障碍服务、通知使用权、悬浮窗 |
| `scripts/logs.sh` | 实时查看守门日志 |
| `scripts/pull-db.sh` | 把电视上的数据库拷回本机核对 |
| `scripts/revoke.sh` | 撤销权限并卸载，不影响 Aerial 和原厂设置 |

电视地址默认 `192.168.50.171:5555`，可用 `TV=地址:端口 ./scripts/install.sh` 覆盖。

家长密码默认 `0000`，首次进入家长页后请修改。

## 结构

| 文件 | 作用 |
|---|---|
| `Db.kt` | 本地数据库：时间流水、答题记录，余额上限、3 天内同题不重复奖励 |
| `GuardService.kt` | 守门服务：识别前台应用、读取播放状态、每秒计时、每 15 秒落盘、余额为 0 时拦截、调试浮层 |
| `MediaListener.kt` | 仅用于取得通知使用权，以便读取播放状态；不读取通知内容 |
| `MainActivity.kt` | 孩子端首页：余额、答题赚时间、开始看电视 |
| `QuizActivity.kt` | 答题页：20 以内加减法 10 题一轮 |
| `ParentActivity.kt` | 家长页：受管应用、开关、测试工具、流水 |

计时级别：
- **A 级**：读取媒体会话，状态为"正在播放"才扣时（需要通知使用权）
- **B 级**：应用没有媒体会话时，在前台且有声音输出才扣时

## 测试清单

准备：家长页勾选要测的视频应用，打开调试浮层，电脑上运行 `scripts/logs.sh`。

### A. 答对加时间
- [ ] 答对 1 题，余额 +1:00，提示"增加 1 分钟"
- [ ] 余额 59:30 时答对，只加 30 秒并提示已满；满 60:00 后答对提示"余额已满"
- [ ] 一题只能提交一次（选项提交后变灰）
- [ ] 答错不加不扣，提示正确答案
- [ ] 同一题 3 天内再次答对，提示"已经奖励过"
